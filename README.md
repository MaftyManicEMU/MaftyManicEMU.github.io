# The Broken Year

Official website for *The Broken Year* by M. Laurence Scott.

## Local development

```bash
pnpm install
pnpm dev
```

## GitHub Pages

Pushes to `main` build a static export and deploy `dist/client` through GitHub Actions. The custom domain is `thebrokenyear.com`.

Full manuscript and interior PDF files are intentionally excluded from version control. The public sample reader uses only the selected, watermarked PNG excerpts in `public/assets/samples/`.
